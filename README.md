# 📐 ALGEBRA MASTER

Plataforma interactiva para aprender Matemática, desarrollada para la Unidad Académica Charagua (Formación Docente).

🔗 **Aplicación en línea:** _(pega aquí el enlace de tu app cuando la publiques)_

## Contenidos

- **Ecuaciones de primer grado:** resolución paso a paso con verificación.
- **Ecuaciones cuadráticas:** discriminante, fórmula general y gráfica de la parábola.
- **Simplificación algebraica.**
- **Factorización:** con identificación del método usado.
- **Operaciones con conjuntos:** unión, intersección, diferencias y diagrama de Venn.

## Ejecutar en tu computadora

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tecnologías

Python, Streamlit, SymPy, Matplotlib y NumPy.
